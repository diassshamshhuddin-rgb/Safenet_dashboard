# SafeNet KZ — Цифровой щит против незаконных схем в соцсетях и мессенджерах

> **ВАЖНОЕ ПРАВИЛО СИСТЕМЫ (ДИСКЛЕЙМЕР):**  
> Система **не объявляет схемы незаконными** и не выносит юридических вердиктов.  
> Система выявляет **признаки возможного нарушения**, оценивает уровень риска и подготавливает объяснительную базу для ручной проверки профильным аналитиком/модератором в соответствии с законодательством Республики Казахстан.

---

## 🎯 Цели и треки

Единый движок SafeNet KZ анализирует мультимодальный контент (текст, изображения, метаданные) по трём трекам:
1. **«Розыгрыши под контролем» (лотереи с платным участием)**: поиск признаков взносов/оплаты за билеты, случайного выбора (рандомайзер, «колесо») и выгоды организатора при разделении от легальных бесплатных конкурсов.
2. **«Скрытая игра» (продвижение онлайн-казино)**: выявление маскированных ссылок, зеркал, реферальных кодов, нативной рекламы («заносы», скрины выводов) и каналов-прокладок.
3. **«Стоп-пирамида» (финансовые пирамиды в WhatsApp/Telegram)**: выявление обещаний нереалистичной сверхдоходности, таймеров срочности («осталось 3 места»), реферальных бонусов и переводов на личные карты (Kaspi).

## 📁 Структура репозитория

```
safenet_kz/
├── config/
│   └── settings.yaml           # Пороги рисков, веса модулей, языковые параметры
├── data/
│   ├── raw/                    # Исходные / тестовые выгрузки
│   └── synthetic/              # Синтетический датасет с трудными негативами
├── artifacts/                  # Сохраненные метрики, графы, отчеты
├── src/
│   ├── core/                   # Базовые типы, конфигурация, дисклеймеры
│   ├── preprocessing/          # Мультиязычная нормализация (ru/kk/транслит), маскирование ПДн
│   ├── features/               # Модули признаков по 3 трекам
│   ├── scoring/                # Гибридный скоринг (0-100) и SHAP-интерпретация
│   ├── graph/                  # Графовый анализ связей (аккаунты, карты, домены)
│   ├── multimodal/             # OCR скриншотов
│   ├── explanation/            # Формирование карточки признаков для модератора
│   └── api/                    # REST API (FastAPI)
├── dashboard/                  # Рабочее место аналитика (Streamlit)
├── tests/                      # Модульные и интеграционные тесты
├── docker-compose.yml          # Запуск одной командой
├── Dockerfile                  # Контейнеризация сервиса
└── requirements.txt            # Зависимости проекта
```

## 🚀 Быстрый старт

### Вариант 1: Docker (рекомендуется)
```bash
docker compose up --build
```
- API доступно: `http://localhost:8000` (Swagger: `http://localhost:8000/docs`)
- Дашборд аналитика: `http://localhost:8501`

### Вариант 2: Локальный запуск
```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск тестов
pytest tests/

# 3. Запуск дашборда
streamlit run dashboard/app.py
```
