# SafeNet KZ — обновленный интерфейс

Из корня проекта (Python 3.10+):

```bash
pip install -r requirements.txt
streamlit run dashboard/app.py
```

При первом запуске создайте администратора. Встроенных паролей нет. Затем войдите через «Вход для администраторов» и создайте сотрудников. Пароль — минимум 10 символов. Сотрудник входит через отдельную вкладку доступа.

Меню: Главная → Профиль → Реестр инцидентов / Управление сотрудниками → Параметры → Поддержка. Нативная кнопка в верхнем углу панели сворачивает ее; кнопка в левом верхнем углу страницы открывает обратно. Язык доступен при входе и в параметрах, тема — в параметрах. Часы обновляются каждую секунду, часовой пояс Казахстана UTC+5.

Учетные записи, решения, обращения и журнал событий сохраняются в `data/workspace.sqlite3`. Путь можно изменить переменной `SAFENET_DB`. Не добавляйте базу в публичный Git. Пароли хешируются PBKDF2-SHA256 с индивидуальной солью. После 5 неверных попыток логин блокируется на 5 минут; сессия действует 8 часов. Отключение сотрудника немедленно отзывает его сессии. Сброс сессии завершает вход, не удаляя сохраненные решения.

Поддержка — внутренний журнал обращений в формате чата; администратор видит все обращения. Автоматическая квитанция не является ответом специалиста. Внешний сервис поддержки, доставка уведомлений и ответы оператора не подключены.

Исходный Repomix не содержит бинарных изображений. Приложение показывает доступные OCR sidecar-файлы с маскированием. Для просмотра оригинальных скриншотов скопируйте изображения в `data/synthetic/images/`. Исходные фрагменты, имена сотрудников и прочие пользовательские данные не переводятся. Интерфейс доступен на русском и казахском.

Метрики качества взяты из исходного `artifacts/metrics.json` и относятся к синтетической тестовой выборке. Это не показатели рабочей системы. Перед сетевым развертыванием ограничьте доступ к первичной настройке, включите HTTPS и используйте корпоративный IdP/MFA при необходимости. Закрытие вкладки не создает событие Logout: оно фиксируется при явном выходе/сбросе; сессия также истекает по времени.

Существующие `src/`, API и наборы данных сохранены; интерфейс заменен модульными `dashboard/app.py`, `store.py`, `translations.py`, `theme.py`.
